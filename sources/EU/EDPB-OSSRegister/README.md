# EU/EDPB-OSSRegister — EDPB Article 60 One-Stop-Shop Register

Final decisions by EU national data protection authorities (DPAs) under the
GDPR cross-border cooperation mechanism (Article 60). Published by the
European Data Protection Board (EDPB).

## Data source

- **Register**: HTML listing pages with structured metadata
- **Full text**: PDF summaries downloaded and extracted via pdfplumber
- **Records**: ~2,400 decisions
- **Coverage**: All EU/EEA DPAs
- **Fields**: case ID, lead SA, concerned SAs, GDPR articles, keywords, outcome
