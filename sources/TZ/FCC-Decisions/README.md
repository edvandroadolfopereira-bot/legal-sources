# TZ/FCC-Decisions — Tanzania Fair Competition Commission

Competition decisions (merger approvals, complaint rulings) and provisional
findings published by the Fair Competition Commission of Tanzania.

Data is fetched from the FCC's public REST API at
`https://www.fcc.go.tz/content/v1/publications/published-publications/list`.

The API is paginated (10 items/page) and returns JSON with bilingual
(English/Swahili) titles and descriptions. Decision descriptions contain
the published summary of the FCC's analysis and ruling (typically 500–850
characters for routine merger approvals).
